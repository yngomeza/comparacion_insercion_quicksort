# Comparación de Inserción y QuickSort

## Descripción
Proyecto de la asignatura Programación Avanzada que compara experimentalmente los algoritmos de ordenamiento Inserción (Insertion Sort) y QuickSort implementados en C++.

## Objetivo
Evaluar el rendimiento de ambos algoritmos según el tamaño y el patrón de los datos de entrada, considerando el tiempo de ejecución, las comparaciones, los intercambios o movimientos y la profundidad de recursión cuando corresponda.

## Metodología
Se evaluarán diferentes tamaños de entrada y cinco patrones: aleatorio, ascendente, descendente, casi ordenado y con duplicados. Se realizarán ejecuciones repetidas para obtener estadísticas descriptivas y elaborar tablas y gráficos comparativos.

## Tecnologías
- C++
- Git y GitHub
- Python para el análisis y la visualización de resultados, si corresponde.

## Estructura del repositorio
- `src/`: código fuente de los algoritmos.
- `data/`: datos de entrada.
- `results/`: resultados experimentales en CSV.
- `scripts/`: scripts para generar gráficos.
- `docs/`: artículo final y diapositivas.
